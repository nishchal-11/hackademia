# Hackademia: AI-Enhanced CI/CD Pipeline
## Overview
This project implements an intelligent CI/CD pipeline using AI agents to analyze, correct, and test code submitted via GitHub pull requests.

## Setup
1. Install Python 3.9+.
2. Set up virtual environment: `python -m venv venv`
3. Activate: `.\venv\Scripts\Activate.ps1` (Windows)
4. Install dependencies: `pip install -r requirements.txt`
5. Add API keys to `.env`

## Usage
- Push changes to a branch and create a PR to trigger the pipeline.
